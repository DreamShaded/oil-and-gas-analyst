# scripts/

Каталог зарезервирован под парсеры и утилиты выгрузки данных (EIA, OPEC MOMR, IEA OMR, yfinance).

**Содержимое каталога не коммитится в репозиторий** (см. `.gitignore`).
Эти скрипты — внешние, разовые, и могут содержать чувствительные параметры запросов.
В целом парсеры пишу на playwright, ранее на различных headless Chrome поднимал.

Готовые CSV-датасеты складываются в `data/prices/` и `data/reports/`.
